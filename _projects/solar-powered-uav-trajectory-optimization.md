This project optimized solar-powered UAV trajectories to maximize flight time on a single battery charge by coupling flight-dynamics simulation, solar-energy modeling, and neural architecture search.

## Tools

- PyTorch
- PySolar
- Neural Evolution of Augmenting Topologies
- SolarNEAT
- Receding horizon control

## Highlights

- Tuned NEAT genetic algorithms to generate effective neural network architectures for SolarNEAT.
- Built Python simulations to validate flight dynamics and trajectory feasibility.
- Integrated receding horizon control to reduce computational cost.
- Achieved sustained simulated solar-powered flight for 28.5 hours by using the day-night cycle to recharge the aircraft battery.
