Research Interests

Projects

  • Virtual Teach and Repeat via NeRF World Representations

    Aerial-image-based digital twin pipeline for virtually teaching UGV routes before real-world deployment.

    • Developed a pipeline for virtual piloting of a UGV in simulation using a drone-image-trained NeRF reconstruction.
    • Tuned NeRF training parameters for clear, differentiable novel viewpoints of large-scale outdoor scenes.
    • Compared physical and virtual sensor models to align depth and feature information for dataset construction.
  • Autonomous UAV Navigation

    GNSS-denied UAV localization using satellite imagery, inverse NeRF methods, and real image-pose datasets.

    • Worked on GNSS-denied UAV localization below 30 m AGL using Google Earth satellite imagery and inverse NeRF methods.
    • Created image-pose datasets with stereo camera tracking in a VICON lab.
    • Evaluated Google Earth 3D renders against real images using SIFT, SURF, ORB, and SuperPoint.
  • RRT Path Planning and Deep Reinforcement Learning

    Sampling-based path planning work that conditions future RRT samples on previous sampling experience.

    • Modified RRT sampling to condition future states on previous sampling experience.
    • Developed baseline learned-experience systems using Hidden Markov Models and recurrent neural networks.
  • Trajectory Optimization for Solar-Powered UAVs with NEAT

    Trajectory optimization for long-duration solar-powered UAV flight.

    • Built Python simulations and tuned NEAT-based neural network architectures for solar-powered UAV trajectory optimization.
    • Integrated receding horizon control to reduce computational cost.
